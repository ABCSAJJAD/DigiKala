# DigiKala



🛒  Digikala Homepage

A front-end practice project that recreates the homepage of Digikala using pure HTML & CSS.

📌 About the Project

This project is a recreation of the Digikala homepage, created to practice and improve my front-end development skills.

The main focus of this project was building the page structure, styling different sections, and creating a layout similar to the original Digikala website using only HTML and CSS.

🛠️ Technologies

HTML5

CSS3 


 🎯 Purpose

This project was created as a practice project while learning HTML and CSS and is part of my front-end development portfolio.




🚀 How to Run

Clone the repository.

Open the project folder.

Open index.html in your browser.

No additional installation or dependencies are required.
